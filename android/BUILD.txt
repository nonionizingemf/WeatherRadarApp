NOAA Weather Dash Android v2.0.9

API 23 compatibility / Galaxy J3 Luna Pro.

Toolchain:
- Gradle 8.7
- Android Gradle Plugin 8.6.1
- JDK 17
- minSdk 23 / targetSdk 35

Important v2.0.9 fixes based on Galaxy J3 Logcat:
- Leaflet is bundled into the APK at build time instead of being loaded from an external CDN at runtime.
- Map initialization now fails gracefully if the bundled map library is unavailable.
- NOAA timeline overlay checks that the map exists before calling getBounds().
- Timeline scrubbing is debounced to reduce UI load on Android 6 devices.
- Map resize and move handling are throttled/debounced.

The build downloads Leaflet 1.9.4 once during the Gradle build, then packages it in the APK. No runtime CDN dependency is used for the Leaflet map library.
